# Deddy Social Studio public site

Small static site for the Deddy Social Studio project. It contains an overview, privacy notice, and terms page. The pages use only local HTML and CSS.

## Publish with GitHub Pages

1. Create or open the public repository `deddy-social-studio-site`.
2. Upload the contents of this folder to the repository root, including `.nojekyll`.
3. In the repository settings, open **Pages** and choose deployment from the `main` branch and `/ (root)`.
4. Save the setting and use the URL GitHub Pages provides after the first deployment completes.

Review the privacy and terms text against the current app behavior before publishing later updates.
